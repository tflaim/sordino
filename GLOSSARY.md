# Sordino

A browser extension that softens distracting sites with a calm, bypassable pause instead of a wall — like a trumpet mute that softens without silencing.

## Language

### Muting

**Mute**:
To place Sordino's overlay over a site on the user's list while muting is in effect.
_Avoid_: block, blocked, ban, lock

**Muted site**:
A site on the user's list, either from a category or added by hand.
_Avoid_: blocked site, distraction, blacklist

**Category**:
A preset group of muted sites (e.g. Social, Video, News) the user switches on or off as a whole.
_Avoid_: preset list, group

**Overlay**:
The layer Sordino places over a muted site, offering the choice to turn back or bypass.
_Avoid_: block page, block screen, interstitial, wall

### When muting applies

**Schedule**:
A time window on chosen days during which muted sites are muted.
_Avoid_: rule, timer, focus session

**Mute now**:
User-started muting outside any schedule; it always ends at a boundary and never persists indefinitely.
_Avoid_: manual override, start blocking, manual mode

**Pause**:
A user-chosen, finite suspension of all muting.
_Avoid_: snooze, turn off, disable, manual off

**Back to schedule**:
Ending a Mute now or a Pause so muting follows the schedules again.
_Avoid_: resume, reset

### At the overlay

**Turn back**:
Choosing to leave a muted site from the overlay.
_Avoid_: go back (as a noun), give up, success

**Bypass**:
A timed pass through the overlay for one muted site.
_Avoid_: unblock, skip, cheat, override

**Bypass budget**:
The number of bypasses available per day; when it is spent, bypassing remains possible but asks for more friction.
_Avoid_: quick bypasses, allowance, lives
